연결 상태

보안 체크리스트

  • Gemini API 키·봇 토큰은 index.html · app.js · room.js에 절대 넣지 않는다 — 브라우저 localStorage에만
  • 공개 저장소(alfksehfltk1/AI-Hub)에는 스냅샷을 AES-GCM으로 암호화해 올린다 (PIN 없이는 못 읽음)
  • 앱은 PIN 잠금 뒤에 열린다 — 폰을 잠깐 빌려줘도 대화·오더가 보이지 않는다
  • API 키는 브라우저에서만 쓰이고, 화면·로그·저장 파일에 평문으로 남기지 않는다
  • 텔레그램 미러는 켤 때만 전송한다 (기본 꺼짐)

홈 화면에 추가

삼성 인터넷 : 메뉴(≡) → 홈 화면에 추가
크롬        : ⋮ → 앱 설치 / 홈 화면에 추가

추가하면 주소창 없이 단독 앱으로 열립니다. 화면은 마지막으로 받은 스냅샷을 함께 저장해 두어 잠깐 인터넷이 끊겨도 보입니다.
