      설정

      연결 상태를 확인하고, 이 브라우저에서만 쓰는 비밀값을 넣을 수 있습니다.

      연결 상태

      브라우저 로컬 설정 이 브라우저에만 저장

      여기에 넣은 봇 토큰·방 ID로 이 브라우저가 텔레그램에 직접 보냅니다. 값은 이 브라우저의 localStorage에만 남고 어디로도 업로드되지 않습니다.

      ⚠️ 이 버전은 텔레그램 전송만 됩니다. 구글 시트 기록·뀨 웹훅은 서버(server.py)가 필요합니다.

      홈 화면에 추가

      삼성 인터넷 : 메뉴(≡) → 홈 화면에 추가
크롬        : ⋮ → 앱 설치 / 홈 화면에 추가

      추가하면 주소창 없이 단독 앱으로 열립니다. 화면은 마지막으로 받은 스냅샷을 함께 저장해 두어 잠깐 인터넷이 끊겨도 보입니다. 새 내용은 사이트를 새로 열 때 반영됩니다.

      보안 체크리스트

      • 봇 토큰·웹훅 URL을 index.html · app.js · server.py에 하드코딩하지 않는다
      • 서버는 기본 127.0.0.1 바인딩. 외부 공개 시 AIHUB_ACCESS_KEY를 켠다
      • 토큰은 응답·로그·저장 파일에 평문으로 나가지 않는다 (설정 여부만 표시)
      • 시트 공유는 계정 단독 비공개 유지 — 링크 공개 금지
      • 기본은 데모(dry-run). 실제 전송은 --live로 명시할 때만
