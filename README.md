# AI 허브 — 폰에 설치하는 오더 허브 (PWA)

피크리 · 부이 · 키링 · 뀨와 지시를 주고받는 화면을 **홈 화면에 추가해 단독 앱처럼** 쓰는 정적 버전입니다.
서버 없이 GitHub Pages에서 그대로 열립니다.

## 쓰는 법

1. 폰 브라우저(크롬 · 삼성 인터넷)에서 이 사이트를 연다.
2. PIN을 넣어 오더보드를 연다. (한 번 열면 그 기기에서는 다시 묻지 않습니다)
3. 메뉴 → **홈 화면에 추가** → 앱처럼 실행됩니다.
4. `설정` 탭에 텔레그램 **봇 토큰**과 **방 ID**를 넣으면 `지시 남기기`가 텔레그램 방으로 바로 전송됩니다.
   (토큰은 그 브라우저의 `localStorage`에만 저장되고 서버로 가지 않습니다)

## 무엇이 되고, 무엇이 안 되나

| 기능 | 정적 배포(PWA) |
| --- | --- |
| 오더보드 · 토론로그 · 타임라인 보기 | 됨 (암호화된 스냅샷 복호화) |
| 지시 → 텔레그램 방 | 됨 (브라우저에 토큰·방 ID를 넣었을 때) |
| 지시 → 구글 시트 오더보드 새 행 | 안 됨 (서버·`gog` 필요) |
| 지시 → 뀨 웹훅 | 안 됨 (서버 필요) |
| 시트 실시간 읽기 | 안 됨 (스냅샷 기준) |

시트 기록·실시간 읽기까지 쓰려면 PC에서 `server.py`를 띄운 로컬 버전을 씁니다.

## 스냅샷 암호화

`data/snapshot.enc.json`은 **AES-GCM**으로 잠겨 있고, 열쇠는 입력한 PIN에서 **PBKDF2-SHA256**으로 뽑습니다.
PIN과 열쇠는 저장소에 들어가지 않습니다. 스냅샷을 새로 만들 때는 원본 저장소에서:

```bash
python3 tools/build_static.py --pin <PIN>
```

`dist/`가 새로 만들어집니다. PIN을 바꾸면 이전 PIN으로는 열리지 않으니, 기기에서 다시 열 때 새 PIN을 넣으면 됩니다.

## 구성

```
index.html          화면 (잠금 화면 포함)
styles.css          디자인
lock.js             PIN → 복호화 → app.js 로드
app.js              타임라인 · 오더보드 · 지시 전송
sw.js               서비스워커 (앱 껍데기 캐시)
manifest.json       PWA 설정 (standalone, #2563eb)
icons/              192 · 512 · maskable 아이콘
data/snapshot.enc.json  암호화된 오더보드 스냅샷
.nojekyll           GitHub Pages가 파일을 그대로 서빙하도록
```
