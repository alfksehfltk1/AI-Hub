# AI 허브 — 폰에 설치하는 AI 단톡방 (PWA)

피크리 · 부이 · 키링 · 뀨 · 제미나이 · 클로드 여섯 AI와 **실시간으로 대화하는 화면**을 홈 화면에 추가해 단독 앱처럼 쓰는 정적 버전입니다.
서버 없이 GitHub Pages에서 그대로 열립니다.

## 쓰는 법

1. 폰 브라우저(크롬 · 삼성 인터넷)에서 이 사이트를 연다.
2. PIN(920421)을 넣는다. (한 번 열면 그 기기에서는 다시 묻지 않습니다)
3. `설정` 탭 → **Gemini API 키**를 넣고 **저장**한다. 모델은 기본 `gemini-3.5-flash-lite`(가장 빠름).
   - 키 발급: <https://aistudio.google.com/apikey>
   - 키는 그 브라우저의 `localStorage`에만 저장되고 어디로도 올라가지 않습니다.
4. `단톡방` 탭에서 말을 건다. `모두에게`면 **부이 → 키링 → 뀨 → 제미나이 → 클로드 → 피크리**가 이어서 답합니다.
   `@부이`처럼 부르거나 아래 칩으로 대상을 고르면 그 AI만 답합니다.
5. 폰에서 오더를 실제로 돌리려면 `설정` 탭에서
   - **텔레그램 봇 토큰·방 ID**를 넣고,
   - **뀨 웹훅 URL·Secret**을 넣은 뒤 **저장**한다.
   보낸 글이 `[AI허브 오더] @대상` 형식으로 텔레그램 방(피크리 5분 폴링 · 키링 5분 순찰)과 뀨 웹훅으로 **동시에** 날아가고,
   말풍선 아래에 `📡 텔레그램 · 뀨 전달됨` 배지가 뜨다. 스위치는 자격증명이 있으면 기본으로 켜지고, 언제든 끌 수 있다.
6. 메뉴 → **홈 화면에 추가** → 앱처럼 실행된다.

## 무엇이 되고, 무엇이 안 되나

| 기능 | 정적 배포(PWA) |
| --- | --- |
| 실시간 단톡방 (Gemini 직접 호출·스트리밍) | 됨 (브라우저에 API 키를 넣었을 때) |
| 오더보드 · 토론로그 보기 | 됨 (암호화 스냅샷 복호화) |
| 대화 기록 유지 (새로고침해도) | 됨 (`localStorage`) |
| 단톡방 → 텔레그램 방 미러(응답까지) | 됨 (토큰·방 ID 넣고 스위치를 켰을 때) |
| 보낸 글 → 텔레그램 방 + 뀨 웹훅 동시 전달 | 됨 (토큰·방 ID / 웹훅 URL·Secret 을 넣었을 때) |
| 지시 → 구글 시트 오더보드 새 행 | 안 됨 (서버·`gog` 필요) |
| 시트 실시간 읽기 | 안 됨 (스냅샷 기준) |

시트 기록·실시간 읽기까지 쓰려면 PC에서 `server.py`를 띄우는 로컬 버전을 씁니다.

## 스냅샷 암호화

`data/snapshot.enc.json`은 **AES-GCM-256**으로 잠겨 있고, 열쇠는 입력한 PIN에서 **PBKDF2-SHA256(600,000회)** 으로 뽑습니다.
PIN과 열쇠는 저장소에 들어가지 않습니다. 스냅샷을 새로 만들 때는 원본 저장소에서:

```bash
python3 tools/build_static.py --pin <PIN>
```

## 구성

```
index.html          화면 (잠금 화면 포함)
styles.css          디자인
lock.js             PIN → 스냅샷 복호화 → app.js · room.js 로드
app.js              오더보드 · 토론로그 · 설정
room.js             실시간 단톡방 엔진 (Gemini 스트리밍 · 텔레그램/뀨 오더 릴레이)
sw.js               서비스워커 (캐시 aihub-pwa-v20, 네트워크 우선)
preview.html        데스크톱에서 375px 폰 화면으로 보기
manifest.json       PWA 설정 (standalone, #2563eb)
icons/              192 · 512 · maskable 아이콘
data/snapshot.enc.json  암호화된 오더보드 스냅샷
.nojekyll           GitHub Pages가 파일을 그대로 서빙하도록
```

## 새 버전 받기

`sw.js`의 캐시 이름(`aihub-pwa-v20`)을 올려 배포하면, 폰에서 앱을 다시 열 때 새 껍데기를 받습니다.
그래도 예전 화면이 보이면 브라우저에서 사이트를 새로고침하거나 앱을 지웠다 다시 추가하면 됩니다.
